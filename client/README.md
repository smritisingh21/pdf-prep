# PDF Prep — Frontend Client

The frontend web application for **PDF Prep**, built with [React 19](https://react.dev/), [Vite](https://vitejs.dev/), and [Tailwind CSS](https://tailwindcss.com/).

For the complete project documentation, setup guide, and backend instructions, see the main [README.md](../README.md).

---

## 🚀 Features

- **Document Ingestion**: Clean drag-and-drop file uploader with animated progress indicators.
- **Interactive Quiz View**: Multiple-choice study quizzes with instant grading, score review, and answer feedback.
- **Flashcard Study Deck**: 3D animated card flips, full-deck navigation, grid review, shuffle mode, and mastery tracking.
- **Responsive Layout**: Designed for desktop and mobile study sessions with Tailwind CSS and Lucide icons.

---

## 🛠️ Development

### Install Dependencies

```bash
npm install
```

### Run Dev Server

```bash
npm run dev
```

The application runs on `http://localhost:5173` by default and proxies requests to the backend server at `http://localhost:3000`.

### Build for Production

```bash
npm run build
```

### Linting

```bash
npm run lint
```
